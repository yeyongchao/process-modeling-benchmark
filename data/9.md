# Example 10.5 (Singular Control with Direct Transcription).


## Input

Consider a singular optimal control problem defined over the finite time horizon $t \in [0, \pi/2]$. The dynamic system involves three continuous state variables $z_1(t)$, $z_2(t)$, and $z_3(t)$, and one manipulated control variable $u(t)$. The primary objective of this problem is to minimize the final value of the third state variable at the end of the time horizon, $t = \pi/2$.

The dynamic behavior of the system is governed by a set of initial-value ordinary differential equations: the rate of change of the first state is equal to the second state; the rate of change of the second state is directly driven by the control input; and the rate of change of the third state is defined as one-half the square of the second state minus one-half the square of the first state. The system starts from an initial condition where $z_1$ and $z_3$ are exactly 0, while $z_2$ begins at 1. Furthermore, the control profile is bounded physically, requiring the control input to remain strictly between -1 and 1 at all times. The analytic solution of this problem shows a control profile that is singular over the entire time domain.

## Output

### 1. Variables

$z_1(t)$: State variable 1 at time $t$

$z_2(t)$: State variable 2 at time $t$

$z_3(t)$: State variable 3 at time $t$

$u(t)$: Control variable profile at time $t$

### 2. Objective Function

Minimize the final value of the third state variable at $t = \pi/2$:

$$\min_u z_3(\pi/2)$$

### 3. Constraints

Process Model (Differential Equations):

$$\frac{dz_1}{dt} = z_2$$

$$\frac{dz_2}{dt} = u$$

$$\frac{dz_3}{dt} = \frac{1}{2}z_2^2 - \frac{1}{2}z_1^2$$

Initial Conditions:

$$z_1(0) = 0$$

$$z_2(0) = 1$$

$$z_3(0) = 0$$

Control Variable Bounds:

$$-1 \le u(t) \le 1$$

Time Domain:

$$t \in [0, \pi/2]$$
