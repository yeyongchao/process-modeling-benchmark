### Problem 1: Process Identification via Least-Squares Optimization (FOPDT Fit)

## Input

Determine the parameters of a First-Order Plus Dead-Time (FOPDT) model by approximating the open-loop unit-step response of the fourth-order process $G_p(s) = \frac{1}{(s+1)^4}$. Fix the model gain at the process steady-state gain, $K=G_p(0)=1$, and determine the time constant and dead time by minimizing the continuous-time, unweighted squared response error over $0\le t<\infty$.

![alt text](figures/48_psa_example_17_4_1_1.png)

The figure shows the same $G_p$ embedded in a proportional-feedback loop for the surrounding control example; it does not depict the open-loop step-response experiment used for this fit. Use the process transfer function above, not the closed-loop response containing $K_c$, to form $c_p(t)$.

## Output

### 1. Variables

- $K \in \mathbb{R}$: Steady-state gain of the FOPDT model, fixed at $K=1$
- $\tau \in \mathbb{R}^+$: Time constant of the FOPDT model
- $\tau_d \in \mathbb{R}^+$: Dead time (transport lag) of the FOPDT model

### 2. Objective Function

$$\min_{\tau, \tau_d} \int_{0}^{\infty} (c_{p}(t) - c_{m}(t))^2 dt$$

### 3. Constraints


Actual Process Step Response ($c_p$):
$$c_p(t) = 1 - \left( 1 + t + \frac{t^2}{2} + \frac{t^3}{6} \right) e^{-t}$$

FOPDT Model Response ($c_m$):
$$c_m(t)=K\left(1-e^{-(t-\tau_d)/\tau}\right)u(t-\tau_d)$$

Physical Realizability and System Stability:
$$K=G_p(0)=1, \qquad \tau > 0  \  and  \  \tau_d \ge 0$$
