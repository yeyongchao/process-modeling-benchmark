### Problem: Optimal PI Controller Tuning (Minimization of Integral Error Metrics)

## Input

Determine three separate optimal PI controller settings for a feedback control system by independently minimizing the Integral of the Square of the Error (ISE), Integral of the Absolute Value of Error (IAE), and Integral of Time-weighted Absolute Error (ITAE) following a unit-step load disturbance. The system contains a multicapacity process modeled by a fourth-order transfer function $G_p(s) = \frac{1}{(s+1)^4}$.

![alt text](figures/49_psa_example_18_4_1.png)


## Output

### 1. Variables

- $K_c \in \mathbb{R}^+$: Proportional gain of the PI controller
- $\tau_I \in \mathbb{R}^+$: Integral time of the PI controller

### 2. Objective Function

Independently minimize each of the following integral error metrics; each metric defines its own PI tuning problem and no combined multi-objective criterion is used:

- ISE:

  $$\min_{K_c, \tau_I} \int_{0}^{\infty} e(t)^2 dt$$

- IAE:

  $$\min_{K_c, \tau_I} \int_{0}^{\infty} |e(t)| dt$$

- ITAE:

  $$\min_{K_c, \tau_I} \int_{0}^{\infty} t|e(t)| dt$$

The corresponding optimal settings reported for this process are $(K_c,\tau_I)=(2.45,5.51)$ for minimum ISE, $(1.66,4.16)$ for minimum IAE, and $(1.18,3.28)$ for minimum ITAE.

### 3. Constraints

Control Law:

$$u(t) = K_c e(t) + \frac{K_c}{\tau_I} \int_{0}^{t} e(\tau) d\tau$$

Error Definition:

$$e(t) = r(t) - c(t)$$

Closed-loop Process Dynamic:

$$\frac{d^4c(t)}{dt^4} + 4\frac{d^3c(t)}{dt^3} + 6\frac{d^2c(t)}{dt^2} + 4\frac{dc(t)}{dt} + c(t) = u(t) + d(t)$$

Asymptotic Stability:

$$\lim_{t \to \infty} e(t) = 0$$
